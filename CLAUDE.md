# Riv.AI

Plataforma de IA aplicada para donos e gestores de PME no Brasil.
React JSX + Supabase (São Paulo) + Vercel. API Anthropic.

## Regras
- Edição cirúrgica. Nunca reescrever o app inteiro.
- Ler o código existente antes de propor mudança.
- Custo de API Anthropic é restrição em toda decisão.
- Zero jargão técnico na interface.
- Duas abordagens viáveis → perguntar antes de implementar.
- Mudança visual grande → mockup e aprovação antes do código.

## Registro
Sem gamificação, sem emoji, sem microcopy de encorajamento.
Vocabulário: Diagnóstico, Aplicações, Biblioteca.
